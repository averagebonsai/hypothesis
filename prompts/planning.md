# Planning Document

Here, I highlight how I plan to implement the idea, alongside key architectural decisions that were made. 

## High-level Planning Trajectory
I intend to roll out the software in the following phases: 
(1) Validate Bertrand Experiment Economic Properties in a .ipynb file (MVP)
(2) Convert this experiment into a working software, where users can interact with a frontend and view visualisations. 
(3) Structure user inputs for open-ended levers, such as firm heterogeneity (how are the firms different), customer heterogeneity (how are customer groups different, etc.)
(4) Generalise economic experiment to other forms of competition-based experiments using Muse Spark 1.3 Coding Agent
(5) Implement software features: Login, saving to database / AWS S3 bucket, caching, etc.
